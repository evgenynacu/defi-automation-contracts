# AI Assistant Configuration

## Code Modification Preferences
- **Minimal Changes**: Always generate minimal, focused changes that address only the specific task
- **Incremental Updates**: Prefer small, targeted modifications over large rewrites
- **Scope Limitation**: Only modify files and sections directly related to the requested change
- **Preserve Existing**: Keep existing code structure and patterns unless specifically asked to change them
- **Comments**: Always use English for any code, including comments (even if I speak in other languages)
- **Naming**: for ts files use kebab case naming convention
- **Code duplication**: Avoid code duplication. Check if your code change produces code duplication and if it does, suggest refactoring to avoit duplication.

## Response Style
- Focus on the exact problem being solved
- Provide only necessary context and explanations
- Use patches/diffs for code changes when possible
- At the end of the response suggest improvements if you see them

## Default Behavior
- Generate minimal viable changes
- Explain what was changed and why
- Suggest improvements, but do not apply them or generate code for them without acceptance
